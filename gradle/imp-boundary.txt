# imp 边界规则（ADR-0003）
#
# 格式：族列表 => 正则 => 说明
#   - 族列表用逗号分隔，`*` 表示所有族
#   - 构建某版本族时，内容模块（core / wilderness / barren）的源码
#     不得出现匹配该正则的写法
#   - 用 `=>` 而非 `|` 分隔，因为正则本身常用 `|`
#
# 规则意图：版本分叉的 API 必须经由 imp 的版本无关接口访问，
# 而不是让内容模块自己写 `if (version)` 或直接调用只存在于某族的符号。
#
# 由 ./gradlew checkImpBoundary 执行，并挂在各模块 check 之前。

# 1) 26.x 才把 ResourceLocation 改名为 Identifier；
#    构建 1.20 / 1.21 族时内容模块不能用新名字（当前有 17 处，迁移到 imp 后再放开）
1.20,1.21 => net\.minecraft\.resources\.Identifier => Identifier 是 26.x 的名字，旧族需经 imp 访问资源 ID

# 2) 26.x 已无 ResourceLocation；内容模块不得再引用旧名
26.x => net\.minecraft\.resources\.ResourceLocation => 26.x 已改名，须经 imp 访问资源 ID

# 3) 版本注解只属于 imp：内容模块不得自行标注版本差异，
#    否则版本逻辑会散落到各处，imp 也就失去了收敛点
* => org\.polaris2023\.wildwind\.imp\.annotations\.(Since|Until|ParamSince) => 版本注解只允许在 imp 内使用
