# imp 外部符号改名表（ADR-0003）
#
# 用途：把 Minecraft 自身跨版本的改名在调用点自动改写，
#       这样源码里可以用一个统一的名字书写。
#
# 格式：族列表 => 旧名 => 新名 => 说明
#   - 族列表用逗号分隔，`*` 表示所有族
#   - 旧名/新名按【简单名】匹配（不做类型解析，这是已知限制）
#   - 只影响方法调用、字段访问与名字引用，不改类型声明
#
# 注意：按简单名匹配意味着同名不同类的符号会被一起改掉。
# 加规则前先确认该名字在本仓库范围内没有别的含义。

# 示例（默认注释掉，确认可用后再启用）：
# 26.x => getX => getXCoord => 某个坐标访问器在 26.x 改名
