# 书与笔属性记录器

所属模块：**0 · 原野之风：核心（wild_wind_core）**。Minecraft 26.2 / NeoForge，使用原版书与笔，无需新物品、配方或权限。

## 使用

1. 手持原版书与笔（`minecraft:writable_book`），主手／副手均可。
2. 按住潜行键（默认 Shift），右键方块或实体。
3. 手中的书与笔直接变为原版署名书（`minecraft:written_book`），收到“已生成署名属性书”的提示后，松开潜行，正常右键阅读。

书名为 `方块名(方块ID)`，实体使用 `实体类型名(实体ID)`，作者为记录玩家。显示名称随客户端语言翻译，例如 `石头(minecraft:stone)`；实体自定义昵称仍可在正文查看。原版序列化书名最多 32 个字符，超长书名仅截短内部标题，物品显示名称和正文中的完整 ID 保留。

一次使用将当前手中的书与笔转换为署名书，不另外赠送一本。属性快照追加到已有笔记之后，保留原页的原始／过滤文本和其他组件，生成第 0 代原本。最多 100 个保存页，剩余页数不足时不转换、不写入，并提示换书。署名书不可继续追加，下一次记录需要另一本书与笔；旁观模式不记录。没有潜行时保留正常交互；记录时不会同时打开容器、交易或触发生物右键行为。

正文、状态提示和硫方怪原型名称使用翻译组件，支持 `zh_cn` 与 `en_us`。服务端保存字段和参数；客户端读取时按当前语言与实际字体分页，视觉页数可能多于保存页数，重新打开时会重新排版。已有玩家笔记及过滤后的内容保留，不重新排版。内部纯文本标题仍受原版格式约束，完整显示名称保留翻译组件。

可用 `/give @s minecraft:writable_book` 获取测试用书。

## 方块字段

| 字段 | 取值方式 |
| --- | --- |
| 合适挖掘工具 | 检查原版镐、斧、锹、锄、剪刀和剑的实际工具组件；需正确工具掉落时同时校验掉落资格。基础工具用下界合金代表，只报告工具类型，不表示最低材料等级。无需专门工具时显示徒手，无法采集或未知显示 ×。 |
| 硬度 | 点击处当前方块状态的破坏硬度；`-1` 表示不能常规挖掘。 |
| 爆炸抗性 | 方块提供的基础爆炸抗性；不模拟特定爆炸源、实体或爆炸事件。 |
| 引燃几率／烧毁几率 | NeoForge 各面的蔓延／燃烧整数参数，非固定百分比；各面不同时显示范围，均为零显示 ×。 |
| 熔岩可燃性／是否可燃 | 方块在点击位置的 NeoForge 熔岩引燃／火焰可燃性判定，任一面成立显示“是”。 |
| 窒息生物 | 当前状态的 `isSuffocating` 判定。 |
| 红石导体／压断红石线 | 原版红石导体判定；“压断”指放在线路上方时阻断向上阶梯连接，不指破坏或直接移除红石粉。 |
| 固体方块 | 当前状态的原版 `isSolid` 判定，不等同于所有面都完整碰撞。 |
| 活塞推动行为 | 使用原版活塞可推动检查，包括黑曜石、容器、不可破坏方块、伸出活塞等特殊情况；描述单块自身，未模拟周围黏连结构与 12 格推动上限。 |
| 乐器 | 方块作为音符盒配套方块时的乐器。 |
| 方块 ID | 实际注册 ID。 |
| 烧炼时间 | 作为熔炉燃料的燃烧时长，显示秒和游戏刻；不是原料加工时间。 |
| 硫方怪原型 | 当前服务端原型注册表和物品标签的实际匹配。 |
| 最大堆叠／物品 ID | 对应方块物品的实际值；没有对应物品则显示 ×。 |
| 可再生 | 可扩展数据包标签，已知可再生为“是”，明确不可再生为“否”，未知为 ×。 |
| 烧炼加工时间 | 有匹配熔炉配方时显示其加工时长，无配方为 ×。 |

另附维度、坐标、完整方块状态、正确工具掉落要求及硫方怪物理参数。布尔属性不成立、属性不适用或无法确认时显示 **×**，不填虚构默认值。零硬度和零抗性仍是有效数值。

活塞行为严格使用四种文字：

- 不可推动，不可拉动
- 被推动破坏，不可拉动
- 可推动，不可拉动
- 可推动，可拉动

## 实体字段

记录实体 ID、名称、维度和坐标、体积、火焰免疫；生物另有当前／最大生命、护甲、移速、攻击力、击退抗性和氧气。方块专属字段保留并填 ×。

掉落物读取自身物品 ID、最大堆叠、燃料和配方信息；普通生物不会把刷怪蛋冒充其物品 ID。硫方怪读取实际吸收物品及所属原型，并附吸收后的基础物理参数。不会读取箱子内容、命令方块命令、实体私有 NBT，也不改变目标。

## 硫方怪原型与物理参数

沿用需求图中的 13 个分类名称：弹性（橡胶球）、普通（足球）、缓慢平移（药球）、快速平移（高尔夫球）、轻盈（沙滩球）、快速滑行（冰球）、缓慢滑行（冰壶）、缓慢弹性、黏性、高阻力、爆炸、高温、默认。

分类从 `minecraft:sulfur_cube_archetype` 注册表匹配，不通过名称猜测材质。数据包增改标签／原型后，新的记录自动使用更新结果。模组物品只有加入对应原型标签才会归入该类，否则为“默认”；未改变硫方怪本身的行为。

示例：木板 → 弹性，泥巴 → 普通，铁块 → 缓慢平移，苔藓块 → 快速平移，羊毛 → 轻盈，浮冰 → 快速滑行，蘑菇块 → 缓慢滑行，石头 → 缓慢弹性，蜜脾块 → 黏性，灵魂沙 → 高阻力，TNT → 爆炸，岩浆块 → 高温。当前 26.2 普通冰和蜂蜜块不属于对应原型，不能把截图中的大类当成所有方块的逐项定义。

物理页列出击退抗性、弹性、摩擦力修正系数、空气阻力修正系数、水平／垂直击退修正系数、浮力、推动幅度。吸收后的属性使用原版基础属性和匹配原型的实际修改器计算，包括属性上下限；若数据包让同一物品匹配多个原型，按原版顺序叠加。推动幅度按原版玩家推动逻辑计算 `max(0, 1 - 击退抗性)`，没有吸收物品的实体为 0。

这些是当前版本／数据包下的吸收参数，不硬编码旧截图数值，也不代表考虑实体药水、玩家接触速度等后的完整运动轨迹。

## 扩展可再生名单

原版没有通用“可再生”属性，不能从硬度、配方或物品类别准确推断全部内容。因此使用手工维护且可被数据包覆盖的标签：

```text
data/wild_wind_core/tags/item/inspection/renewable.json
data/wild_wind_core/tags/item/inspection/non_renewable.json
data/wild_wind_core/tags/entity_type/inspection/renewable.json
```

例如把模组物品加入可再生名单：

```json
{
  "replace": false,
  "values": ["your_mod:your_item"]
}
```

明确不可再生物品标签优先。预置常用木材、羊毛、部分可循环生成方块和常见可繁殖／自然生成生物；未收录不等于不可再生。荒野通过自己的资源包将泥猪加入实体名单，核心无需依赖荒野。

## 验证

1 项翻译组件保留单元测试、3 组 GameTest：方块属性与四种活塞行为；真实事件总线上的潜行／副手／旁观／满页行为、署名转换、作者与书名、原始／过滤笔记保留、长标题序列化；以及 12 类硫方怪加默认类的注册表匹配与实际实体属性对照。另在核心单独安装测试中生成署名书，在真实客户端字体加载后分别检查中英文、长 ID 和换行的分页，验证阅读不会改写保存内容。署名书编解码测试验证翻译键与参数不会丢失。
