# 杜鹃木展示架\(Azalea Shelf\)

**一种可用于存放和展示物品的功能方块\.**

**合适挖掘工具:斧**

**硬度:2**

**爆炸抗性:3**

**引燃几率:30**

**烧毁几率:20**

**熔岩可燃性:是**

**窒息生物:否**

**红石导体:否**
**压断红石线:否**

**固体方块:是**

**活塞推动行为:不可推动,不可拉动**

**乐器:贝斯**

**地图基色:暂未设定**

**方块ID:azalea\_shelf**

**物品创造标签页:功能方块**

**烧炼时间:300游戏刻\(15秒,1\.5个物品\)**

**最大堆叠:64**

**可再生:是**

**物品ID:azalea\_shelf**

**生成**
**———————————————————**
**杜鹃木展示架不会生成在世界中\.**

**获取**
**———————————————————**

**合成:**
**■杜鹃木展示架x6:**

**▪第一行:去皮杜鹃原木,去皮杜鹃原木,去皮杜鹃原木**

**▪第二行:空位,空位,空位**

**▪第三行:去皮杜鹃原木,去皮杜鹃原木,去皮杜鹃原木**

**破坏**
**———————————————————**

**挖掘杜鹃木展示架的合适工具是斧\.**

**杜鹃木展示架被破坏后会掉落自身和内容物\.**

**用途**
**———————————————————**

**存放物品:**

**杜鹃木展示架正面有3个槽位,可存放最多3组物品\.与任意槽位交互时,玩家的主手物品会与所交互槽位的物品交换\.**

**类似于物品展示框,杜鹃木展示架会在正面展示其包含的所有物品\.但与之不同的是其内部物品不可旋转\.**

**方块实体数据align\_items\_to\_bottom控制了杜鹃木展示架槽位中展示物品的位置\.其值为false\(默认值\)时,物品位置居中；其值为true时,物品置于底部隔板上方\.无法通过命令以外的其他方式修改其值\.**

**激活:**

**■杜鹃木展示架可以被红石信号激活,此时其正面纹理会随之改变,槽位之间的“隔板”会消失\.激活的杜鹃木展示架可以与其他激活的展示架相互连接,最多可以连接3个,相互连接的展示架连接处的“隔板”会消失\.此时,杜鹃木展示架的行为如下:**

**▪与单个杜鹃木展示架交互时,其包含的所有物品会与玩家快捷栏右起3个物品交换\.**

**▪与两个相连接的展示架交互时,其包含的所有物品会与玩家快捷栏右起6个物品交换\.**

**▪与三个相连接的展示架交互时,其包含的所有物品会与玩家快捷栏的所有物品交换\.**

**红石比较器:**

**■红石比较器可以从背面检测展示架内的物品排布,并输出相应强度的红石信号,范围为0–7\.计算方式类似于二进制:**

**▪所有槽位均无物品时,信号强度为0\.**

**▪左、中、右槽位有物品时,信号强度分别增加1、2、4\.**

**■若以○表示该槽位有物品,×表示该槽位无物品:**

**▪槽位顺序为×××时,信号强度增加0,**

**▪槽位顺序为○××时,信号强度增加1,**

**▪槽位顺序为×○×时,信号强度增加2,**

**▪槽位顺序为○○×时,信号强度增加3,**

**▪槽位顺序为××○时,信号强度增加4,**

**▪槽位顺序为○×○时,信号强度增加5,**

**▪槽位顺序为×○○时,信号强度增加6,**

**▪槽位顺序为○○○时,信号强度增加7,**

**容器交互:**
**漏斗****可以为杜鹃木展示架放入或取出物品,****投掷器****和****合成器****可以为杜鹃木展示架放入物品,****漏斗矿车****可以为杜鹃木展示架取出物品\.无论位于杜鹃木展示架的哪一侧,它们总是会与满足条件的左起第一个槽位交互,即以从左到右的顺序放入或取出物品\.多个展示架相连接时,这些方块只会与其直接连接的展示架交互,而无法与连接的其他展示架交互。**

**燃料:**
**杜鹃木展示架可以作为熔炉、高炉和烟熏炉的燃料,每个杜鹃木展示架可以烧炼1\.5个物品\.**
