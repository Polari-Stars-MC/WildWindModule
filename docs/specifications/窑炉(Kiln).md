# 窑炉\(Kiln\)

**专用于烧炼各类建筑材料和染料等杂物的****熔炉****变种\.**

**合适挖掘工具:镐**

**硬度:3\.5**

**爆炸抗性:3\.5**

**窒息生物:是**

**红石导体:是**
**压断红石线:是**

**固体方块:是**

**活塞推动行为:不可推动,不可拉动**

**乐器:底鼓**

**地图基色:暂未设定**

**亮度:13\(燃料燃烧时\)**

**方块ID:kiln**

**物品创造标签页:功能方块**

**最大堆叠:64**

**可再生:是**

**物品ID:kiln**

**生成**
**———————————————————**
**自然生成:**

**窑炉会生成在****村庄****的石匠屋中\.**

**获取**
**———————————————————**

**合成:**
**■窑炉:**

**▪第一行:空位,红砖,空位**

**▪第二行:红砖,熔炉,红砖**

**▪第三行:泥坯,泥坯,泥坯**

**破坏**
**———————————————————**

**挖掘窑炉的合适工具是镐。窑炉需要木镐或品质更好的镐来挖掘，否则挖掘时间将延长且不会掉落\.**

**窑炉被破坏后会掉落自身、内容物和储存的经验值\.**

**用途**
**———————————————————**

**窑炉不能被****活塞****推动\.**

**烧炼:**
**窑炉只能****烧炼****矿物、金属工具、武器和盔甲以外的物品\.速度为每100****游戏刻****\(5秒\)烧炼一个物品,即每分钟烧炼12个物品,是****熔炉****的2倍\.**

**使用窑炉可以打开它的界面\.下方的槽位为"燃料槽",用于放置燃料\(最多1组\),上方的槽位为“烧炼槽”,用于放置烧炼物\(最多1组\),右侧的槽位为"成品槽",烧炼成品会存放于此\(最多1组\)\.**

**连接到窑炉上面的****漏斗****会向烧炼槽中添加烧炼物,连接到窑炉侧面的漏斗会向燃料槽中添加燃料,窑炉下面的漏斗会取走成品槽中的成品和燃料槽中的****铁桶****,如果铁桶与成品槽的成品同时存在会优先吸取成品\.**

**烧炼产生的经验会存储在窑炉中,当玩家取出成品槽中的成品或窑炉被破坏时一并给予玩家\.**

**燃烧中的窑炉会生成烟雾和火焰****粒子****\.**

**红石比较器:**
**红石比较器****可检测窑炉的内容物占空比,烧炼槽、燃料槽和成品槽都会被统计\.**

**光源:**

**燃烧中的窑炉会发出****亮度****等级为13级的光\.**

**自定义名称:**

**窑炉界面的标题默认为“窑炉”,可以在未放置之前使用铁砧重命名来进行更改,也可以通过使用****`/`****`data`****命令修改窑炉的****`CustomName`****标签进行更改\.**

**锁定:**

**窑炉可以被****`lock`****标签上锁\.如果窑炉的该标签不是空白的,那么这个窑炉必须使用符合该标签表示的物品谓词的物品打开\.**
