# 杜鹃木告示牌\(Azalea Sign\)

**一种可以显示文本的方块\.**

**合适挖掘工具:斧**

**硬度:1**

**爆炸抗性:1**

**引燃几率:0**

**烧毁几率:0**

**熔岩可燃性:是**

**窒息生物:否**

**红石导体:否**
**压断红石线:否**

**固体方块:是**

**活塞推动行为:不可推动,不可拉动**

**乐器:贝斯**

**地图基色:暂未设定**

**方块ID:azalea\_sign**

**物品创造标签页:功能方块**

**烧炼时间:200游戏刻\(10秒,1个物品\)**

**最大堆叠:16**

**可再生:是**

**物品ID:azalea\_sign**

**生成**
**———————————————————**
**杜鹃木告示牌不会生成在世界中\.**

**获取**
**———————————————————**

**合成:**
**■杜鹃木告示牌x3:**

**▪第一行:杜鹃木板,杜鹃木板,杜鹃木板**

**▪第二行:杜鹃木板,杜鹃木板,杜鹃木板**

**▪第三行:空位,木棍,空位**

**破坏**
**———————————————————**

**挖掘杜鹃木告示牌的合适工具是斧\.**

**杜鹃木告示牌被破坏后会掉落自身\.**

**用途**
**———————————————————**

**放置:**

**杜鹃木告示牌必须放置在固体方块（包括栅栏、玻璃、其他告示牌）的顶部或侧面。放置在方块顶部的杜鹃木告示牌会竖立在一根短标杆上,朝向放置此杜鹃木告示牌的玩家,总共可朝向16个不同的方向\.放置在方块侧面的杜鹃木告示牌会附在该方块的侧表面,当该方块侧面不完整时则飘浮在其所在格的侧表面\.**

**杜鹃木告示牌会在其附着的方块移动或被移除的情况下被破坏并掉落自身\.**

**文本:**

**杜鹃木告示牌的正面和背面都可以显示文本，一个面最多可输入4行文本。**

**放置杜鹃木告示牌时会自动打开杜鹃木告示牌正面的文本编辑界面。如果放置的杜鹃木告示牌已经有文本了\(如通过物品数据添加\),那么杜鹃木告示牌被放置后不会出现文本输入界面\.**

**输入时可使用鼠标或方向键移动光标位置。点击“完成”或者Esc按钮可以关闭文本输入界面\.**

**当编辑窗口关闭后,对着已放置的杜鹃木告示牌按下使用键可重新打开编辑窗口,以编辑其正面或背面的文本\.**

**对着杜鹃木告示牌使用蜜脾可以涂蜡，涂蜡后的杜鹃木告示牌不再能被编辑文字、染色或改变发亮效果,若要修改则需破坏后重新放置杜鹃木告示牌\.**

**对有文字的杜鹃木告示牌使用染料可以改变文本颜色\.**

**■杜鹃木告示牌上显示的文字不受周围亮度影响\.对杜鹃木告示牌使用荧光墨囊可以提高文本亮度,使用墨囊可以移除发亮效果\.杜鹃木告示牌文字被增亮后会出现外边框,边框颜色随文字颜色而定:**

**杜鹃木告示牌文本可以包含****格式化代码****\.杜鹃木告示牌文本可使用****文本组件****\.**

**如果有其他玩家正在编辑杜鹃木告示牌内容,则不能与该杜鹃木告示牌进行任何交互\.**

**交互:**

**杜鹃木告示牌没有碰撞箱,因此****实体****可以穿过杜鹃木告示牌\.其他方块\(包括其他告示牌\)可以被放在杜鹃木告示牌的任何一角\.**

**活塞无法推动杜鹃木告示牌\.杜鹃木告示牌被活塞拉动时不会有反应\(除非杜鹃木告示牌附在伸出的活塞头表面\)\.**

**水****和****熔岩****会绕开杜鹃木告示牌流动\.杜鹃木告示牌不会被****火****燃尽\.**

**燃料:**
**杜鹃木告示牌可以作为熔炉、高炉和烟熏炉的燃料,每个杜鹃木告示牌可以烧炼1个物品\.**

**安全保护:**
**杜鹃木告示牌属于“仅管理员可设置数据”的方块\.**

**非管理员玩家对杜鹃木告示牌按下Ctrl\+选取方块时不会复制方块实体数据,放置物品栏中已有的带有方块实体数据的杜鹃木告示牌也不会将数据实际加载\.**

**管理员玩家的物品栏中如果携带着有方块实体数据的杜鹃木告示牌,物品****提示框****中会显示警告信息\.**
