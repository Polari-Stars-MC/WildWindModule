# 延展之箭\(Tipped Arrow\)

**具有药水效果的箭变种，可以对击中的生物施加延展状态效果\.**

**物品创造标签页:战斗物品**

**最大堆叠:64**

**可再生:是**

**物品ID:wwhfas:tipped\_arrow**

**实体ID:wwhfas:arrow**

**获取**
**———————————————————**

**交易:**

**■交易目标:大师级制箭师村民**

**▪概率:67%概率**

**▪收购物品:绿宝石x2,箭x5**

**▪出售物品:延展之箭x5**

**药水箭的交易选项会从除水瓶、粗制的药水、平凡的药水和浓稠的药水制成的药箭外的所有生存模式可获取的药箭中随机选择,包括所有的改性变种\.其中也包含延展之箭\.**

**礼物:**

**制箭师会向带有村庄英雄效果的玩家投掷延展之箭\.**

**当玩家在村庄获得村庄英雄效果后,制箭师会从箭、抗火之箭、伤害之箭、治疗之箭、隐身之箭、跳跃之箭、夜视之箭、剧毒之箭、再生之箭、迟缓之箭、力量之箭、迅捷之箭、水肺之箭、虚弱之箭、延展之箭中随机选取投掷给予玩家\.其中也包含延展之箭\.**

**合成:**

**■B**

**▪第一行:箭,箭,箭\.**

**▪第二行:箭,A,箭\.**

**▪第三行:箭,箭,箭\.**

**当A为滞留型延展药水\(03:00\)时,B为延展之箭\(00:22\)x8\.**

**当A为滞留型延展药水\(08:00\)时,B为延展之箭\(01:00\)x8\.**

**用途**
**———————————————————**

**具有无限魔咒的弓在使用延展之箭射击时,药箭会被正常消耗\.**

**行为**
**———————————————————**

**延展之箭具有与箭相同的行为。**

**延展之箭在卡进方块30秒后,会集中散发一次药水粒子效果,随后丢失所有的药水效果数据\.此时再次捡起只会获得普通的箭\.**

**造成状态效果:**

**延展之箭在命中生物时会对其施加延展状态效果\.**
